# Week 7: Statistical Business Analysis

This project applies descriptive statistics, hypothesis testing, confidence intervals, correlation analysis, and regression analysis to business data.

## Files

- `statistical_analysis.ipynb` - notebook walkthrough of the analysis.
- `statistical_analysis.py` - reproducible script that regenerates all deliverables.
- `business_data.csv` - cleaned business dataset built from the supplied sales and churn data.
- `statistical_report.pdf` - final statistical report with methodology, results, charts, and recommendations.
- `hypothesis_tests_results.txt` - plain-text hypothesis test summary.
- `requirements.txt` - required Python libraries.

## Run

```bash
pip install -r requirements.txt
python statistical_analysis.py
```

## Key Results

- Average sales revenue: INR 123,650
- Revenue 95% confidence interval: INR 103,776 to INR 143,525
- Marketing spend and revenue correlation: 0.89
- Regression R-squared: 0.89
- Hypothesis tests completed: 4
