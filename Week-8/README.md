# Week 8: Capstone Project - Real World Business Analysis

## Project Overview

This capstone project solves a customer retention business problem using an end-to-end data analysis workflow. The main dataset is `customer_churn.csv` with 500 rows, which satisfies the 500+ row requirement. Supporting sales and house-price datasets are included as portfolio context.

## Business Problem

The business needs to reduce preventable churn and protect recurring revenue. The analysis identifies churn patterns, high-risk customer groups, and an implementation plan for retention action.

## Key Results

- Churn rate: 10.6%
- Average monthly charge: INR 114
- Churned customer value at risk: INR 41,598
- Highest risk contract segment: Month-to-month
- Analysis techniques: EDA, segmentation, hypothesis testing, correlation analysis, logistic regression
